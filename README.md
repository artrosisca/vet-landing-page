# Landing Page - Médica Veterinária

Landing page acolhedora, responsiva e de alta conversão para atendimento veterinário com agendamento direto via WhatsApp.

## 🚀 Inspiração e Conceito
Baseado no benchmark de atendimento veterinário humanizado (`vetanacastro.com.br`), facilitando o contato do tutor com a veterinária em poucos cliques.

## 📁 Estrutura de Documentação
- `AGENTS.md`: Diretrizes e convenções para agentes de desenvolvimento.
- `CONTEXT.md`: Glossário e contexto do domínio.
- `docs/agents/`: Configurações de issue tracker, etiquetas de triagem e regras de documentação.
- `docs/adr/`: Registros de Decisões de Arquitetura (ADRs).
